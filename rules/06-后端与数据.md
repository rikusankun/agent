# 后端与数据

做窗口、动数据库时先过这 4 条。底线同时有效。不管用 Python 还是别的语言，都算。

窗口就是别人来交数据、要数据的口子。数据库就是存数据的仓库。一张表就是一类东西的名单。

1. 必须先检查别人传来的数据是不是空的、缺一块、格式不对。是就直接打回。禁止拿去用。

2. 必须在窗口报错时回一个明确的结果：没填全、不让进，还是我们自己坏了。禁止不回话就把线掐断。

3. 必须在出错时马上写进日志：第几条、哪个文件、为什么坏。禁止把错误吞掉。必须把一条坏数据记下来再继续。禁止一条坏掉就让整批崩掉。

日志就是跑起来时写下的记录，人要能看见。

4. 必须在删除或覆盖之前先列出清单，并确认三遍：动哪张表、哪几条、删了还能不能找回。三遍没齐，禁止动手。禁止一句话把整个仓库删掉。
